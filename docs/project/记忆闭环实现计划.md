# 工作空间 Agent 记忆闭环实现计划

## Summary

- 仅补齐工作空间 Agent：有界短期历史、结构化工作记忆、语义/情节/程序长期记忆、混合检索、时间衰减、定期审查和安全迁移。
- 客户记忆、单向 ACL 与 `trade_rag` 保持隔离，不复用其表、索引或发布状态。
- 长期记忆一律先进入 `pending_confirmation`；只有明确确认后才能召回。
- 当前功能开关保持关闭，完成迁移快照和验收后再受控开启本地运行；外部 Embedding 默认不启用。

## Implementation Changes

### 短期记忆与结构化工作记忆

- 继续使用完整轮次裁剪和冷归档；保留最近 10 个完整用户轮次，不拆分 tool-call/result 组，摘要失败时保留原历史。
- 将工作记忆固定为：当前目标、已确认事实、已确认结论、待验证假设、待办、已完成事项；每项保存来源、确认状态和更新时间。
- 在用户消息、成功工具结果和最终回答三个事件点生成严格 JSON Patch，并以乐观版本写入；用户明确输入可确认当前任务目标，模型推断和任意工具文本默认保持 pending。
- 修复成功工具调用没有触发 `observe_tool_result` 的链路；记忆提取失败只记录稳定错误码，不阻断 Agent 主回答。
- 重构最终回答持久化顺序：先完成记忆生命周期，再将候选提示一次性附加到回答并保存，避免重复 assistant 消息。

### 长期记忆与检索

- 扩展工作空间权威 SQLite Store，使其完整支持候选、确认、拒绝、纠正/替代、软删除、导出、按项目隔离及索引 outbox；工作空间表继续禁止出现客户 `account_id`。
- 自动提取仅在完整轮次结束后运行，生成语义、情节或程序候选；保存来源引用、置信度、重要性、敏感级别、内容哈希和版本，不保存思维过程。
- 为工作空间建立独立关键词索引和向量索引，使用现有 RRF 融合、权威主存二次校验和幂等 outbox Worker；索引失败不改变权威记忆状态。
- 默认使用本地 `local_hash` 离线适配器；新增 OpenAI-compatible Embedding 适配器，但只有外部传输批准开关、地址、模型、密钥和维度全部有效时才允许启动。`restricted` 记忆永不外传。
- 最终召回分数使用 RRF、重要性、置信度和类型半衰期共同计算；默认半衰期为语义 180 天、情节 30 天、程序 365 天。无显式到期时间的记忆只降权、不自动删除。
- 显式 `expires_at` 到期后自动失效；每 168 小时运行一次冲突/合并/淘汰审查，LLM 结果只生成待确认建议，不直接修改有效记忆。

### 确认、管理与迁移

- 增加确定性对话命令：`/memory candidates`、`/memory confirm <id> <version> <hash>`、`/memory reject ...`、`/memory forget ...`、`/memory review`；普通“好的/确认”不能直接激活记忆。
- 增加受保护的 `/api/workspace/memories` 管理 API，提供分页查询、详情、确认、拒绝、纠正、删除、导出和触发审查；所有写操作要求版本和内容哈希，重复请求幂等，过期版本返回 409。
- API 默认回环地址免密；远程访问必须使用独立 Bearer Token并通过 Origin 校验，不复用邮箱管理令牌。
- 使用规范化工作区绝对路径的哈希作为稳定 `project_id`，同一项目跨会话共享，不同 checkout 严格隔离；操作者身份来自可信进程配置。
- 提供 `MEMORY.md` 迁移命令，支持 `--dry-run` 和 `--apply`：按条目幂等导入为语义候选，来源指向原文件行号，绝不直接激活、覆盖或删除原文件。
- 开启前保存会话、`MEMORY.md`、`HISTORY.md` 和数据库清单/哈希；候选确认完成前保留只读 legacy fallback，验收后再停止把旧 Markdown 注入提示词。
- 同步更新 `docs/archive/记忆管理.md`、项目进度、变更记录和运行手册，分别陈述本地实现、当前启用状态、离线检索质量和生产门禁。

## Public Interfaces and Configuration

- `MemoryStatus` 新增 `pending_confirmation`；客户侧原有 `pending_consent` 语义保持不变。
- `WorkspaceWorkingMemory` 改为带来源和状态的类型化模型；turn/tool 事件增加稳定 source reference。
- 新增工作空间专用配置：自动提取、混合检索、治理/审查、管理 API 令牌与 Origin、各类型半衰期、审查间隔，以及独立 Embedding backend 配置。
- 外部 Embedding 配置缺失、未批准、模型维度变化或受限数据外传时全部 fail closed；检索可明确降级为关键词模式，但不得静默切换模型或跨索引版本读取。

## Test and Acceptance Plan

- 单元测试：工作记忆 Patch/状态迁移、来源保留、乐观冲突、三类候选校验、确认前不可召回、纠正替代、软删除和跨项目拒绝。
- Agent 链路测试：用户→工具→最终回答完整更新工作记忆；成功/失败工具钩子正确；候选提示只出现一次；提取器或存储故障不丢对话、不产生已确认事实。
- 检索测试：关键词/向量融合、权威二次校验、半衰期排序、显式过期、索引重试/重建、模型版本不匹配、外部传输门禁和 restricted 拒绝。
- API/命令测试：本机与远程鉴权、Origin、分页、版本/hash 门禁、幂等、非法确认语句、导出和删除。
- 迁移测试：dry-run 零写入、重复 apply 不重复、全部导入为待确认、原 `MEMORY.md` 字节不变、不同 checkout 的 `project_id` 不同。
- 端到端验收：新会话创建目标和假设→工具验证→候选生成→确认前不召回→精确确认→另一会话召回→随时间降权→显式到期失效→审查建议仍待确认；重启后状态和索引一致。
- 执行工作空间记忆专项、根目录全量测试，并单独运行 `test2/rag_knowledge_base`，避免测试收集冲突；使用固定脱敏评估集分别报告 local-hash 链路结果与真实语义 Embedding 结果。
- 验收通过后先启用本地工作空间记忆和本地索引，保留回退开关；外部 Embedding、远程管理和生产定时审查继续关闭，直到单独完成数据传输批准和线上质量验收。

## Assumptions

- 采用未回复问题的推荐默认：按项目路径隔离、本机免密远程令牌、无显式期限只降权。
- 记忆只作为辅助上下文，不能成为报价、库存、审批、邮件发送或交易状态的权威来源。
- 本次不建设新的前端记忆管理页面；对话命令和管理 API 构成完整确认入口。
- 本地哈希向量只证明链路可运行，不宣称达到生产语义检索质量。
