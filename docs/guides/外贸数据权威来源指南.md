# 外贸数据权威来源指南

> 核验日期：2026-07-27（Asia/Shanghai）  
> 用途：为市场选择、产品分析、贸易趋势判断和 RAG 知识库提供可追溯的公开数据入口。  
> 边界：这里只整理公开、聚合数据源，不收集个人信息、买家联系方式或来源不明的“海关交易明细”。

## 一、推荐数据源

| 数据源 | 适合解决的问题 | 主要数据维度 | 访问说明 | 官方入口 |
|---|---|---|---|---|
| 海关总署统计查询 | 中国进出口总量、商品、贸易伙伴和时间趋势 | 商品、国家或地区、进出口方向、期间等；具体字段以查询页面为准 | 官方查询站对本次自动请求返回 HTTP 412，建议在浏览器中人工查询和下载，不应绕过访问控制 | [海关统计查询](http://stats.customs.gov.cn/) |
| 商务部商务数据中心 | 中国商务运行、对外贸易、投资与合作相关公开数据 | 数据集各自定义 | 2026-07-27 可访问；下载格式、更新周期和授权以数据集页面为准 | [商务数据中心](https://data.mofcom.gov.cn/) |
| UN Comtrade | 按申报国、伙伴国、商品和流向分析全球货物贸易 | Reporter、Partner、Flow、Period、HS/SITC、贸易额、重量、数量 | 公共 preview API 可直接访问；开发者门户会跳转登录。preview、汇总值和估算值不能当成最终申报明细 | [Comtrade Plus](https://comtradeplus.un.org/) · [开发者门户](https://comtradedeveloper.un.org/) |
| WTO Stats | 比较各经济体货物贸易、服务贸易和相关统计指标 | 指标、经济体、时间、产品或服务分类 | 2026-07-27 可访问；批量下载和指标说明以门户元数据为准 | [WTO Stats](https://stats.wto.org/) |
| World Bank WITS | 联合查看贸易、关税和非关税措施 | Export、Import、Tariff、NTM、国家、产品、年份 | 2026-07-27 可访问；部分分析或下载流程可能要求登录 | [WITS](https://wits.worldbank.org/) |
| ITC Trade Map | 产品—市场组合、竞争国和目的市场比较 | 产品、国家、贸易伙伴、时间、贸易额和数量 | 首页可访问；部分功能可能需要注册，额度与许可应以页面提示为准 | [ITC Trade Map](https://www.trademap.org/) |
| World Bank Indicators API | 获取适合趋势图和宏观对照的标准指标 | 国家、指标、年份、数值、更新时间 | 无密钥示例接口在核验时可直接返回 JSON | [World Bank API](https://api.worldbank.org/) |

## 二、按业务问题选数据源

| 业务问题 | 首选 | 交叉验证 | 注意事项 |
|---|---|---|---|
| 中国某类商品出口到哪些市场 | 海关总署 | UN Comtrade、Trade Map | 固定 HS 版本、出口方向、年度或月份口径 |
| 全球某产品的主要进口市场 | UN Comtrade | Trade Map、WITS | 区分进口国申报值和出口国镜像值 |
| 判断目标市场关税和非关税壁垒 | WITS | WTO、ITC Market Access 工具 | 普通税率不等于企业实际适用税率；原产地规则需单独核验 |
| 比较国家整体贸易规模 | WTO Stats、World Bank | UN Comtrade | 商品贸易与货物和服务贸易不能混用 |
| 中国商务运行与政策背景 | 商务部、海关总署 | WTO、World Bank | 政策文件与统计数据应分别保存发布日期和适用期 |

## 三、已验证的 API 示例

### 1. UN Comtrade：中国 2024 年对世界商品出口预览

```text
GET https://comtradeapi.un.org/public/v1/preview/C/A/HS
    ?reporterCode=156
    &period=2024
    &cmdCode=TOTAL
    &flowCode=X
    &partnerCode=0
    &partner2Code=0
    &customsCode=C00
    &motCode=0
    &maxRecords=5
    &typeCode=C
    &freqCode=A
    &clCode=HS
```

2026-07-27 实际响应包含一条汇总记录：

- `reporterCode=156`（中国）
- `period=2024`
- `flowCode=X`（出口）
- `cmdCode=TOTAL`
- `primaryValue=3576543293842`
- `fobvalue=3576543293842`
- `isAggregate=true`
- `isReported=false`

这是一条 preview 汇总结果，不应描述为企业交易明细或最终无修订统计。

### 2. World Bank：中国商品出口指标

```text
GET https://api.worldbank.org/v2/country/CHN/indicator/TX.VAL.MRCH.CD.WT
    ?format=json
    &date=2023:2024
    &per_page=10
```

核验响应中的指标为 `Merchandise exports (current US$)`：

| 年份 | 数值（current US$） |
|---:|---:|
| 2023 | 3,379,044,000,000 |
| 2024 | 3,575,795,000,000 |

API 元数据的 `lastupdated` 为 `2026-07-13`。该数值与 UN Comtrade preview 略有差异，说明跨源分析必须保留数据来源和版本，不能只按“国家 + 年份”直接覆盖。

## 四、下载和入库建议

1. 先保存原始下载文件，不直接覆盖；文件名加入来源、数据集、提取日期和参数摘要。
2. 同时保存请求 URL、查询条件、下载时间、页面或 API 的版本说明。
3. 国家使用 ISO3，商品编码同时保存 `hs_version` 和 `hs_code`，不要只存商品名称。
4. 金额至少保存币种、计价口径和原始数值；不要默认所有贸易额都是美元 FOB。
5. 月度数据显式区分单月值和累计值；年度数据不要与年内累计值拼接。
6. API 返回的 `isReported`、`isAggregate`、估算标志和缺失值必须原样保留。
7. 对外输出结论时至少用两个来源交叉检查；不一致时解释口径，而不是取平均值。

## 五、合规与使用限制

- 只使用公开、授权的数据接口或人工下载功能，遵守网站服务条款、频率限制和署名要求。
- 不绕过登录、验证码、HTTP 412/403、访问配额或反自动化措施。
- 不购买或导入来源不明、含自然人联系方式、报关主体隐私或未经授权的交易级数据。
- 聚合统计只能支持市场判断，不能作为具体客户信用、库存、报价或合规结论的唯一证据。
- 关税、制裁、出口管制和原产地结论需回到对应主管机构的当前规则核验。
