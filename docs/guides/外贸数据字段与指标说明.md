# 外贸数据字段与指标说明

> 目标：把不同来源的公开贸易数据整理成可比较、可复算、可追溯的本地数据。  
> 本文只定义分析字段和公式，不替代各数据源的官方元数据。

## 一、推荐的最小字段集

| 字段 | 含义 | 示例 | 校验要求 |
|---|---|---|---|
| `source` | 数据来源 | `UN_COMTRADE` | 使用固定枚举 |
| `dataset` | 数据集或指标代码 | `TX.VAL.MRCH.CD.WT` | 不只保存中文名称 |
| `retrieved_at` | 获取时间 | `2026-07-27T00:00:00Z` | UTC ISO 8601 |
| `source_updated_at` | 来源更新时间 | `2026-07-13` | 来源未提供时为 null |
| `reporter_iso3` | 申报国 | `CHN` | ISO3；同时保留来源原始代码 |
| `partner_iso3` | 伙伴国 | `WLD` | 世界汇总与未知值不得混淆 |
| `period` | 统计期 | `2024`、`2024-06` | 与频率配套 |
| `frequency` | 频率 | `A`、`M` | 年度与月度分开 |
| `flow` | 贸易方向 | `EXPORT` | 明确进口、出口、再出口等 |
| `classification` | 商品分类 | `HS` | 保存分类体系 |
| `hs_version` | HS 版本 | `H6` | 跨版本必须映射后再比较 |
| `hs_code` | 商品编码 | `TOTAL`、`850440` | 保留前导零 |
| `trade_value` | 贸易额 | `3576543293842` | 使用十进制或整数，不用二进制浮点累计 |
| `currency` | 币种 | `USD` | 禁止省略 |
| `valuation` | 计价口径 | `FOB`、`CIF` | 进口与出口常有差异 |
| `net_weight_kg` | 净重 | 具体数值或 null | 0 与缺失必须区分 |
| `quantity` | 数量 | 具体数值或 null | 必须搭配数量单位 |
| `quantity_unit` | 数量单位 | `kg`、`items` | 单位转换后保留原始单位 |
| `is_reported` | 是否直接申报 | `false` | 保留来源标志 |
| `is_aggregate` | 是否汇总 | `true` | 汇总行不能与明细重复求和 |
| `estimation_flag` | 估算或镜像标志 | 来源原值 | 不自行改写成“真实值” |
| `source_url` | 查询或下载地址 | 完整 URL | 便于复核 |

## 二、常用指标和公式

### 同比增长率

```text
同比增长率 = (本期贸易额 - 上年同期贸易额) / 上年同期贸易额
```

上年同期为 0 或缺失时返回 null，不输出无限大。

### 贸易差额

```text
贸易差额 = 出口额 - 进口额
```

必须确保币种、期间、商品范围、伙伴范围和估值口径一致。

### 市场份额

```text
市场份额 = 某出口国对目标市场的该商品出口额 / 目标市场该商品总进口额
```

分子和分母最好来自同一来源、同一 HS 版本；否则在结果中标注口径差异。

### 单位价值

```text
单位价值 = 贸易额 / 数量或净重
```

单位价值不是实际成交单价。数量单位不一致、重量估算或贸易结构变化都会造成偏差。

### 复合年增长率（CAGR）

```text
CAGR = (期末值 / 期初值)^(1 / 年数) - 1
```

期初值和期末值必须大于 0；只有两个端点时不能反映中间波动。

### 市场集中度（HHI）

```text
HHI = Σ(各市场份额²)
```

计算前需去除世界汇总行、未知伙伴和重复汇总层级。

## 三、最常见的口径陷阱

1. **FOB 与 CIF**：出口通常按 FOB，进口常按 CIF；同一贸易流的两端申报值不会天然相等。
2. **镜像数据**：一国缺报时可能使用伙伴国申报值，必须保留估算和申报标志。
3. **HS 版本变化**：同一个六位码在不同 HS 修订版中可能拆分、合并或改变含义。
4. **汇总重复**：`TOTAL`、两位章、四位品目和六位子目不能放在一起直接求和。
5. **单月与累计**：海关月度页面可能同时提供当月和累计值，字段名必须明确。
6. **0 与缺失**：0 可能是估算、无贸易或占位；null 才表示来源未提供，需查元数据。
7. **商品与服务**：UN Comtrade 的货物贸易不能直接替代 WTO 或宏观指标中的服务贸易。
8. **名义值与实际值**：current US$ 会受价格和汇率影响，不能直接解释为实际贸易量增长。
9. **再出口与特殊贸易制度**：香港、新加坡等转口枢纽尤其需要检查贸易制度和再出口口径。
10. **数据修订**：同一来源也会回修历史值，本地数据必须保存提取时间和来源更新时间。

## 四、推荐的 SQLite 表结构

```sql
CREATE TABLE trade_observation (
    source TEXT NOT NULL,
    dataset TEXT NOT NULL,
    retrieved_at TEXT NOT NULL,
    source_updated_at TEXT,
    reporter_iso3 TEXT NOT NULL,
    reporter_source_code TEXT,
    partner_iso3 TEXT,
    partner_source_code TEXT,
    period TEXT NOT NULL,
    frequency TEXT NOT NULL,
    flow TEXT NOT NULL,
    classification TEXT,
    hs_version TEXT,
    hs_code TEXT,
    trade_value TEXT,
    currency TEXT,
    valuation TEXT,
    net_weight_kg TEXT,
    quantity TEXT,
    quantity_unit TEXT,
    is_reported INTEGER,
    is_aggregate INTEGER,
    estimation_flag TEXT,
    source_url TEXT NOT NULL,
    raw_record_json TEXT NOT NULL,
    PRIMARY KEY (
        source, dataset, reporter_source_code, partner_source_code,
        period, frequency, flow, hs_version, hs_code
    )
);
```

金额和数量用文本或定点十进制进入清洗层，避免 SQLite/Python 二进制浮点累计误差；分析时再转换为受控 Decimal。

## 五、导入知识库前的检查清单

- 数据来源、URL、提取时间和许可说明齐全。
- 原始文件与清洗文件分开保存，保留 SHA-256。
- 国家代码、伙伴代码、HS 版本、流向、频率和币种非空。
- 汇总层级明确，不存在重复求和。
- `is_reported`、`is_aggregate` 和估算标志未被删除。
- 示例、估算和正式统计有明确标签。
- 文档只包含公开聚合信息，不含个人或企业敏感交易明细。
